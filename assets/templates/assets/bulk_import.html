  • Category, Asset Tag and Name are required; everything else is optional.
  • Category must match an existing category name exactly (not case-sensitive).
  • Asset Tag must be unique — not already used, and not repeated in the file.
  • Status accepts values like Working, Not Working, Idle, Scrap, Missing, Under Service (defaults to Working if blank).
  • Dates should be YYYY-MM-DD (e.g. 2025-01-15) — a few common alternatives like DD-MM-YYYY and DD/MM/YYYY are also accepted, but YYYY-MM-DD is never ambiguous.
Multiple sheets (.xlsx with 2+ tabs):
  • Each sheet tab name is matched to a category by name (case/spacing-insensitive) or a few built-in aliases (e.g. a tab named "Bluetooth" imports into "Bluetooth Device"). A tab named "Monitor" imports into the Monitor category.
  • Sheets can use their own real column names — there's no need to rename anything to "Asset Tag" or "Name". If no column looks like an Asset Tag, the sheet's first column is used as the unique ID automatically; if there's no obvious Name column, one is generated from the category + ID.
  • Any other columns (Monitor's Type/Color/Size, System's Processor/RAM/OS Type, etc.) are kept as-is against each asset — whatever they're called.
  • Tabs that don't match any category still import, under the catch-all "Other Asset" category, so nothing is silently dropped. Only tabs that are completely empty are skipped. Both are listed after validation — the rest of the file still imports.
